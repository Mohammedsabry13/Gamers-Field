# GamersField — Arabic Gaming E-Commerce Website

A fully Arabic RTL front-end for **GamersField**, Egypt's go-to gaming store established in 2019. Selling laptops, desktop PCs, internal components, and gaming accessories with 100% authentic products and competitive pricing.

## 🛠️ Tech Stack

- **HTML5 & CSS3** — semantic RTL structure and custom styling
- **Bootstrap 5.0 RTL** — full right-to-left responsive layout
- **Font Awesome 5.9** — icon set
- **Alexandria** — Google Fonts Arabic typography
- **Vanilla JavaScript (OOP)** — HeroSlider class, search overlay, touch/swipe support

## 📄 Pages

- `index.html` — Home (Hero, Category Gallery, Products)
- `products.html` — Products listing page
- `basket.html` — Shopping cart page
- `profile.html` — User profile page
- `about.html` — About GamersField
- `contact.html` — Contact page
- `404-page.html` — Custom 404 with auto-redirect countdown

## ✨ Features

- **Animated hero slider** (OOP class) with 3 slides, per-element enter animations (slideInUp, slideInScale), keyboard arrow support, touch/swipe gesture support, and dot navigation
- **Category gallery grid** — Laptops, Mouse, Keyboard, Headphones
- **Product grids** — Laptops section + Accessories section, each with promo card and "View More" link
- **Fullscreen search overlay** — opens on icon click with focus trap, closes on backdrop click or Escape key
- **Shopping cart icon** with link to basket page
- **User profile page** with account UI
- **Custom 404 page** with gamepad icon, quick-links pills, and 15-second auto-redirect countdown
- **About page** — Story, Values cards (Quality, Pricing, Support, Delivery), and CTA section
- **Multi-level dropdown navbar** — Devices, Internal Components, Accessories
- **Full RTL layout** — Bootstrap 5 RTL + Arabic Alexandria font throughout
Fully responsive across all screen sizes
